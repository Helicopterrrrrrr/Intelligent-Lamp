# 肩宽归一化和角度判断实现总结

## 实现时间
2026-05-26

## 实现目标
解决姿态检测系统在不同机位、不同用户下泛化性差的问题，通过肩宽归一化和角度相对判断提升准确性。

## 核心改进

### 1. 数据结构扩展

**PoseFeatures 新增字段**：
```python
head_shoulder_distance_ratio: float  # 头肩距离/肩宽，归一化特征
neck_angle_deg: float                # 颈椎角度（鼻子-肩膀-臀部）
```

**ReferenceFeatures 新增字段**：
```python
head_shoulder_distance_ratio: float  # 正常坐姿的头肩距离比例
torso_angle_deg: float               # 正常坐姿的躯干角度
head_tilt_deg: float                 # 正常坐姿的头部倾斜角度
```

### 2. 特征提取增强

在 `feature_extractor.py` 中新增：
- 头肩距离归一化计算
- 颈椎角度计算（三点角度）
- 使用新增的 `angle_three_points` 几何函数

### 3. 规则引擎重构

在 `rules.py` 的 `_evaluate_posture` 方法中实现双模式判断：

**模式1：基于参考值的归一化判断**（有标定时）
- 头部距离比例相对于参考值的偏差
- 颈椎角度绝对阈值（30°）
- 躯干角度相对于参考值的偏差

**模式2：固定阈值判断**（无标定时）
- 保留原有的固定阈值逻辑作为 fallback
- 确保向后兼容

### 4. 标定系统升级

`ReferenceCalibrator` 现在采集：
- 肩宽像素值
- bbox 面积比例
- 头肩距离比例
- 躯干角度
- 头部倾斜角度

计算平均值作为用户个性化参考。

### 5. 配置文件更新

`configs/default.yaml` 新增阈值：
```yaml
head_distance_ratio_threshold: 1.3      # 头部距离比例阈值
torso_angle_deviation_deg: 15.0         # 躯干角度偏差阈值
head_tilt_deviation_deg: 15.0           # 头部倾斜偏差阈值
neck_angle_threshold_deg: 30.0          # 颈椎角度阈值（医学标准）
```

## 技术亮点

1. **归一化消除尺度影响**
   - 使用肩宽作为归一化基准
   - 头肩距离比例不受身高、机位距离影响

2. **相对判断提升泛化性**
   - 相对于用户正常坐姿的偏差
   - 适应不同用户的坐姿习惯

3. **医学标准支持**
   - 颈椎角度 30° 阈值参考医学研究
   - 前倾头姿态（Forward Head Posture）检测

4. **向后兼容**
   - 无标定时自动使用固定阈值
   - 不影响现有功能

5. **双层判断**
   - raw_label: 实时姿态判断
   - event_label: 持续时间过滤后的事件触发
   - 减少误报
