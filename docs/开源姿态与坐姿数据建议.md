# 开源姿态与坐姿数据建议

下面这几类数据适合当前 SmartLED 的验证和后续微调。

## 1. 立即可用的快速验证数据

### COCO8-Pose

- 用途: 快速验证推理、关键点绘制、脚本是否能跑通
- 特点: Ultralytics 官方的超小样例数据，适合 sanity check，不适合桌前场景结论
- 链接:
  - https://docs.ultralytics.com/datasets/pose
- 说明: 只有 8 张图，适合先验证导出脚本和可视化

### COCO-Pose

- 用途: 通用人体关键点效果验证
- 特点: 官方姿态估计大数据集，17 个关键点，覆盖面大
- 链接:
  - https://docs.ultralytics.com/zh/datasets/pose/coco
  - https://cocodataset.org/
- 说明: 适合检查模型对多种人体姿态的稳定性，但“书桌前学习”样本占比不高

### MPII Human Pose

- 用途: 检查模型在日常活动场景下的姿态泛化
- 特点: 官方数据集，约 25K 图像、40K 人体、410 类日常活动
- 链接:
  - https://www.mpi-inf.mpg.de/departments/computer-vision-and-machine-learning/software-and-datasets/mpii-human-pose-dataset
- 说明: 活动多样性强，适合作为补充验证集

## 2. 更贴近“桌前坐姿”的公开数据

### FYP posture - sitting posture

- 用途: 桌前坐姿粗分类参考
- 特点: Roboflow Universe 公开数据，273 张图，`Good/Bad`
- 链接:
  - https://universe.roboflow.com/fyp-posture/sitting-posture-rofqf-6rhwd
- 许可证: CC BY 4.0
- 说明: 更贴近当前项目语义，但规模较小，建议只做规则校准或补充微调

### FYP posture - Desk Posture

- 用途: 桌前颈部/上半身关键点思路参考
- 特点: Roboflow Universe 公开数据，71 张图，类名为 `person-torso` 和 `textneck`
- 链接:
  - https://universe.roboflow.com/fyp-posture/desk-posture-sywmc
- 许可证: CC BY 4.0
- 说明: 很小，但和书桌场景最接近，适合做早期误判分析

### Sitting Posture v2

- 用途: 坐姿领域补充数据
- 特点: Roboflow Universe 公开项目，655 张图，带 train/valid/test 划分
- 链接:
  - https://universe.roboflow.com/ikornproject/sitting-posture-rofqf/dataset/2
- 说明: 社区数据，质量需要自己抽样检查

## 3. 推荐使用顺序

1. 先用 COCO8-Pose 验证脚本和导出结果
2. 再用 COCO-Pose / MPII 检查通用关键点稳定性
3. 最后用桌前坐姿数据做误判分析和微调准备

## 4. 当前项目如何跑这些数据

### 跑图片文件夹

```powershell
python scripts/export_inference.py --input data/images --output-dir output/inference/images
```

### 跑单个视频

```powershell
python scripts/export_inference.py --input data/videos/demo.mp4 --output-dir output/inference/video
```

### 带参考标定跑

```powershell
python scripts/export_inference.py --input data/videos/demo.mp4 --reference calibration/reference.json --output-dir output/inference/video
```

## 5. 解释当前“只看到姿态识别正常”的现象

当前界面现在区分两层输出:

- `posture(raw)`: 每帧的原始姿态判断
- `posture(event)`: 满足持续时间阈值后，真正触发提醒的事件姿态

如果你看到关键点识别正常、但 `posture(event)` 一直是 `normal`，通常表示:

1. 你的人体已经被正确检测
2. 但还没有持续超过异常阈值
3. 或者 ROI / 距离阈值 / 头部下沉阈值还需要按你的机位校准

建议先看 `posture(raw)` 和 `distance(raw)`，再决定是否调规则。
